Sources & teaching choices

One continuous interactive adaptation of Nipun Batra’s ML and DL CNN lectures, shaped by the teaching rhythm of the attention series.

The core is about 100–130 minutes with student predictions and experiments. For a shorter class, teach the operator, representation, shared-gradient, and training sequence; assign the architectural bridges as reading.

Online lecture and technical references

Stanford CS231n 2025 · Lecture 5, Image Classification with CNNs

Reference for connecting affine layers to convolution and for following the tensor transformation through a network. This version makes the local dot products editable. Official lecture video.

Michigan EECS 498/598 · Justin Johnson, Convolutional Networks

Reference for explicit shapes, parameter sharing, and layer-by-layer numerical reasoning. Used alongside the existing ML lecture’s architecture worksheet.

MIT OpenCourseWare · CNNs and Transfer Learning

Reference for the practical transition from image features to a pretrained backbone and a new classifier. The browser toy is explicitly separated from real transfer evidence.

Dive into Deep Learning · From fully connected layers to convolutions

The locality and sharing derivation motivates treating convolution as an architectural constraint. The channel chapter supports the distinction between summing input slices and stacking output filters.

Distill · Computing Receptive Fields of Convolutional Neural Networks

Reference for receptive-field size, effective stride, and the distinction between possible and effective influence. The lesson adds a live support map showing dilation holes.

Richard Zhang, ICML 2019 · Making Convolutional Networks Shift-Invariant Again

Motivates testing the failure of shift invariance and discussing low-pass filtering before subsampling. No claim that pooling automatically guarantees invariance.

CS231n convolutional-network notes

A supporting reference for local connectivity, weight counts, and the channel-spanning filter. Here, legal output placements use the general floor formula.

CNN Explainer · Wang et al.

Further interactive reading: inspect how a complete CNN connects individual operations. The present lesson’s browser experiment is a separate original six-example model.

PyTorch Conv2d documentation

Implementation contract for cross-correlation, NCHW, weight shape, groups, stride, padding, and dilation. See the companion for executable parity checks.

Review used available lecture slides, official notes, and papers; it did not involve watching each lecture video end to end. All worksheets, prose, diagrams, and browser code here are newly authored adaptations of the course material, not copied lecture figures.

Evidence, conventions, and limits

The photograph is Abyssinian_1 from the Oxford-IIIT Pet dataset, Parkhi et al., “Cats and Dogs,” CVPR 2012. The repo records CC BY-SA 4.0; copyright remains with the original image owner. The two bundled derivatives retain that license. The real-image worksheet resizes the head crop to 160×160, converts RGB to grayscale using 0.299R + 0.587G + 0.114B, and computes the selected operator live.

The binary band image is a declared pedagogical simplification from the existing L8 evidence. Its 45×45 crop is x∈[328,373), y∈[120,165). It is separate from the head-ROI crop used for the real-image filtering worksheet.

Signed response colors always distinguish negative, zero, and positive. Matrix values are rounded for display; calculations use JavaScript double precision. Bias counts are explicit; MACs exclude bias additions, nonlinearities, and pooling unless stated.

The six bar images, channel worksheet, pooling values, and shift impulses are synthetic teaching constructions. The tiny CNN is trained live and reports only training performance. There is no pretrained vision model, network call, or hidden simulated training curve.

The browser model and its initial values are shared by the training and forward-pass widgets. Pixel edits deliberately stay local to the convolution worksheet; independent examples start from the values stated on their frames.
