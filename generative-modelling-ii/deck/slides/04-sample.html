Invert the jump formula to guess the clean value

$x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon$
$\Rightarrow\quad \hat x_0 = \dfrac{x_t - \sqrt{1-\bar\alpha_t}\,\hat\epsilon}{\sqrt{\bar\alpha_t}}$

Bayes' rule on the forward steps: q(x_{t−1} | x_t, x₀) ∝ q(x_t | x_{t−1}) q(x_{t−1} | x₀), both Gaussians we know. The product is a Gaussian (appendix A2 completes the square). Read the mean as a weighted blend of x₀ and x_t.

Toy numbers, t = 2: both weights happen to be 0.894 × 0.2 / 0.36 = 0.497. Result 0.745.

Ask: at generation time, which ingredient is missing? x₀. That is the whole problem, and the next slide's fix is the obvious one.

The complete sampler

The loop from the first slide, in ten lines

x = torch.randn(B, 1, 28, 28)               # x_T
for t in range(T, 0, -1):                   # 1000, 999, ..., 1
    tt = torch.full((B,), t)
    eps_hat = model(x, tt)
    c = beta[t] / (1 - alpha_bar[t]).sqrt()
    mean = (x - c * eps_hat) / alpha[t].sqrt()
    if t > 1:
        x = mean + post_var[t].sqrt() * torch.randn_like(x)
    else:
        x = mean                            # last step: no noise
start from pure noise
one network call per step, same weights
the mean formula
fresh noise with the shape of x

1000 network calls for one batch of images. Sampling is slow; training was one call per example.

beta, alpha = 1 − beta and alpha_bar are the Part 1 tables; post_var[t] = β_t(1 − ᾱ_{t−1})/(1 − ᾱ_t) is β̃_t.

The loop runs from T down to 1. The step number is given to the network every time.

The mean formula from two slides back, for every pixel at once.

torch.randn_like(x) draws noise with x's shape. A common bug is torch.randn() with no shape, which adds the same single number to every pixel. Appendix A7 shows a faster sampler (DDIM) that uses 50 calls.

What we did, and what comes next

What we did

  1. Invert the jump formula to guess the clean image: $\hat x_0 = 0.925$ (true 1).
  2. Knowing $x_0$, the backward step is a Gaussian with mean 0.745; with the guess instead, 0.708.
  3. Add fresh noise $\sigma_t z$ at every step but the last: 0.708 → 0.808. Without it, every sample is the same “1”.
  4. Repeat 1000 times from pure noise: the loop on the first slide.
